Channel Ops

Privacy policy

Last updated 7 November 2026

Channel Ops is a private tool. Only its owner uses it, and only on the owner's own YouTube channels. This page explains what it does with YouTube data.

YouTube API Services

Channel Ops uses YouTube API Services: the YouTube Data API and the YouTube Analytics API. Google's handling of data is covered by the Google Privacy Policy. Using Channel Ops means agreeing to the YouTube Terms of Service.

What it reads

Details of the owner's channels and videos: titles, descriptions, tags, privacy and schedule settings, captions and playlists. From YouTube Analytics it reads view counts and where the views came from, such as the Shorts feed. These reports are totals and don't identify individual viewers.

What it changes

On the owner's own channels only, it can upload a video, add captions, add a video to a playlist or remove it from one, and set a video to private. It has no way to delete videos.

What it keeps, and where

  • The permission Google issues for the owner's channels (an OAuth refresh token) is kept in the owner's private Claude Code environment settings, never in a file or a repository.
  • A short log of video IDs, view counts, dates and actions taken is kept in the owner's private GitHub repository.
  • The daily check runs in the owner's own Claude Code cloud workspace (Anthropic), which handles this data only to carry out the check.

Nothing is sold, used for advertising, or shared with anyone else. Channel Ops stores nothing on your device, and this website sets no cookies. The site is hosted on GitHub Pages, so GitHub may record visits as described in the GitHub Privacy Statement.

Removing access

Access can be removed at any time on the Google Account permissions page, security.google.com/settings/security/permissions. Channel Ops then stops working until access is granted again.

Contact

Questions about this policy can be left as an issue in this site's GitHub repository.

Changes

If this policy changes, the date at the top changes with it.
