Channel Ops

Channel Ops is a small private tool its owner uses to look after their own YouTube channels.

Once a day it checks how each new Short is doing. If YouTube never showed one in the Shorts feed, it uploads the same video again on the same channel and sets the first copy to private. It never deletes videos.

It isn't offered to anyone else, and there is nothing to sign up for.

Channel Ops uses YouTube API Services. Using it means agreeing to the YouTube Terms of Service.
